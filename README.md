# Hamid Oyempemi — Portfolio

Personal site for Hamid Oyempemi, Senior Mobile Engineer.

## Stack

- Vite
- React + TypeScript
- Tailwind CSS
- shadcn/ui

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev      # http://localhost:8080
```

## Scripts

- `npm run build` — production build to `dist/`
- `npm run preview` — serve the production build locally
- `npm run lint` — run ESLint

## Editing content

All site copy (projects, experience, engineering areas, links) lives in `src/data/portfolio.ts`. Components in `src/components` only handle presentation.
